# CloudNova Technologies — Demonstration Service Catalogue (Fictional)
Version: 1.0 | Training document only

## About CloudNova
CloudNova Technologies is a fictional managed-cloud consultancy used for the KICS Huawei Cloud RAG lab.
Our training service categories are Cloud Migration, Database Reliability, Data Analytics, and AI Knowledge Assistants.

## Cloud Migration
CloudNova prepares architecture assessments, VPC designs, ECS modernization plans, networking reviews and application containerization.
Every proposal includes a network diagram, resource inventory, and backup / rollback plan.

## Database Reliability
CloudNova supports MySQL backup reviews, managed RDS primary/standby high availability, read replicas for analytic reads and DRS migration exercises.
A read replica is not a replacement for a tested disaster-recovery strategy.

## AI Knowledge Assistant
The AI Knowledge Assistant uses retrieval augmented generation (RAG) to answer questions from uploaded documents.
It stores structured application records in MySQL or SQLite, and embeddings in Qdrant.
The local language model runs on Ollama and does not need an external paid AI API.

## Customer response objectives
The fictional support team targets an initial acknowledgement within four business hours for standard tickets.
Critical incidents are acknowledged within 30 minutes during business hours.

## Data handling
Customer documents should be accessed only by approved team members. The lab version uses a shared knowledge base for enrolled users and must not be used for sensitive commercial data.

All service descriptions and response objectives above are fictional and for classroom use only.
